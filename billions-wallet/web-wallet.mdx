## Overview

The Web Wallet runs entirely in the browser, letting you claim, manage, and present credentials without installing anything. It verifies against both on-chain and off-chain requests, so the same wallet plugs into dApps and traditional web services alike.

## Quick Start

The Web Wallet is accessible at [wallet.billions.network](https://wallet.billions.network). To get started, sign in with Google, Apple ID, or a crypto wallet, and create your identity.

<Info>
  Zero-knowledge proof generation runs entirely in the browser using a WebAssembly-compiled circuit client. No personal data or cryptographic material leaves the user's device at any point during proof generation.
</Info>

<Info>
  **Credential Sync** — credentials sync automatically via end-to-end encrypted cloud storage. Sign in with the same account — Google, Apple ID, or crypto wallet — on the web or mobile wallet, and any credentials already claimed on one platform are immediately available on the other, with no need to re-claim them.
</Info>
