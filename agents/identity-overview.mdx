The **Verified Agent Identity** skill gives any AI agent a decentralized, cryptographic identity (DID) on the Billions Network — and lets a human owner link themselves to that agent permanently and verifiably on-chain.

Once linked, the agent can prove it is operated by a real, unique human. This unlocks discounted pricing tiers on APIs protected by x402 Human Proof, spam protection for service providers, and a public, tamper-proof record of agent ownership that anyone can verify.

<Info>
  **What is x402 Human Proof?** x402 is an open payment protocol that lets APIs accept per-request payments. x402 Human Proof extends it with a human identity verification layer — so providers can offer better pricing to verified humans and the agents they control, while keeping standard rates for unverified traffic. [Learn more](/agents/overview)
</Info>

The demo walks through the full identity linking flow live — from a fresh agent with nothing installed to a permanent, on-chain human-agent pairing — using a Telegram bot called Billy running on [OpenClaw](https://openclaw.ai), an agent framework for building and deploying AI agents.

### What happens in the demo

<Steps>
  <Step title="Install the skill">
    An agent called Billy was built using OpenClaw and deployed on Telegram. [Clawhub](https://clawhub.ai) — the skill manager for OpenClaw-compatible agents — handles the install. With the agent running, a single install command is pasted directly into the chat:

    ```plaintext
    Install the skill `npx clawhub@latest install verified-agent-identity`
    ```

    Billy installs the skill and sets everything up automatically — no manual configuration needed.
  </Step>
  <Step title="Agent generates its DID">
    The user asks Billy to show his identity. Billy responds with his DID — a decentralized identifier derived from his cryptographic key via the [iden3 protocol](https://docs.iden3.io), an open-source ZK identity framework. No one assigned it; the math created it.
  </Step>
  <Step title="Generate a pairing link">
    The user sends: "Link my DID with yours." Billy generates a verification URL scoped specifically to this human-agent pair and shares it in the chat.
  </Step>
  <Step title="Complete pairing in the Billions Web Wallet">
    The user opens the link in the Billions Web Wallet and signs in with Google. The wallet loads the user's identity and existing credentials.

    New users complete a one-time face scan here to claim a Proof of Uniqueness credential. Once claimed, it is stored in the wallet and never needs to be repeated.
  </Step>
  <Step title="On-chain attestation is created">
    The user hits **Verify**. The wallet generates a zero-knowledge proof and submits it to the Relay Attestation Service, which calls the Identity Verifier Contract to verify the proof on-chain, then calls the Attestation Registry Contract to create a permanent attestation linking the user to Billy.
  </Step>
  <Step title="Ownership is public and verifiable">
    The pairing is now on-chain, permanent, and verifiable by anyone. The user can view Billy listed under **Verified Agents** in their profile — the last four characters of Billy's DID (`V9HT`) match exactly what was shared in the Telegram chat.
  </Step>
</Steps>
