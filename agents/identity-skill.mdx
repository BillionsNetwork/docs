By the end of this guide your agent has its own DID, and an ownership attestation on production links that DID to you. It takes two chat messages and one approval in your wallet. For what the skill does behind the scenes, see [Agent Identity](/agents/identity-overview) and [How Pairing Works](/agents/identity-architecture).

## Before you start

- **An agent that can install skills**, on an OpenClaw-compatible runtime. The skill sends you messages through the **`openclaw` CLI**, which must be in the agent's `PATH`.
- **Node.js 20 or later** and **npm**, on the machine where the agent runs. The skill is a set of Node scripts.
- **A [Billions Web Wallet](https://wallet.billions.network) account.** If you haven't claimed a [Proof of Uniqueness credential](/billions-wallet/proof-of-uniqueness) yet, the wallet walks you through it during pairing, with a one-time face scan.

## 1. Install the skill

Ask your agent directly, with any one of these:

```plaintext
Install the skill `npx clawhub@latest install verified-agent-identity`
```

```plaintext
Install the skill `npx skills add BillionsNetwork/verified-agent-identity`
```

```plaintext
Install the skill https://github.com/BillionsNetwork/verified-agent-identity
```

[clawhub](https://clawhub.ai) is the skill manager for OpenClaw-compatible agents, and [skills.sh](https://skills.sh) is a universal skill registry for AI agents. The agent installs the skill and does the basic setup on a supported runtime. If the agent has no identity yet, the skill creates a key pair and a DID before pairing.

<Accordion title="Where the key lives" icon="key">
  The skill stores the agent's private key in `~/.openclaw/billions/kms.json`, outside the agent's workspace.

  By default the key is written as **plain hex**, readable only by your OS user. Anyone or any process that can read that file can sign as your agent. Before deploying anywhere that matters:

  - **Encrypt the key at rest.** Set the `BILLIONS_NETWORK_MASTER_KMS_KEY` environment variable before the skill creates or imports a key, and it stores the key with AES-256-GCM instead.
  - **Restrict the folder.** Run `chmod 700 ~/.openclaw/billions` after the first run.
  - **Use a dedicated key.** If you import your own key with `--key`, use one made for this agent. Never import a wallet key that holds funds.

  The full policy, including what the skill does and doesn't defend against, is in the [skill's security policy](https://github.com/BillionsNetwork/verified-agent-identity/blob/main/SECURITY.md#storage-modes).
</Accordion>

## 2. Link your agent

Once installed, tell your agent to link its identity to you:

```plaintext
Link your agent identity to me.
```

The agent will generate a verification link scoped to this specific human-agent pairing. Open it in the [Billions Web Wallet](https://wallet.billions.network), sign in, and hit **Verify** to complete the on-chain pairing. If you haven't already claimed a [Proof of Uniqueness credential](/billions-wallet/proof-of-uniqueness), the claim process, a one-time face scan, starts automatically. If you have, it's reused for every future verification.

For a step-by-step explanation of what happens during the pairing, see [How Pairing Works](/agents/identity-architecture#the-linking-flow).

## 3. Verify it worked

- Ask your agent to show its identity. It responds with its DID.
- Open your profile in the [Billions Web Wallet](https://wallet.billions.network) and check **Verified Agents**. Your agent is listed there, and the last characters of its DID match what it showed you in chat.

The attestation is now on-chain. The pairing record is public. Applications should check its current validity and separately verify control of the agent DID.
