The Billions Docs MCP gives your AI assistant direct access to Billions documentation through the [Model Context Protocol](https://modelcontextprotocol.io/).

Use it when you want Claude, Codex, Cursor, VS Code or another MCP client to search the current Billions docs while you build.

## Endpoint

```text
https://docs.billions.network/mcp
```

The docs MCP does not require authentication.

## Connect your client

<Tabs>
  <Tab title="Claude Code">
    ```bash
    claude mcp add --transport http --scope project billions-docs https://docs.billions.network/mcp
    ```
  </Tab>
  <Tab title="Codex">
    ```bash
    codex mcp add billions-docs --url https://docs.billions.network/mcp
    ```
  </Tab>
  <Tab title="Cursor">
    Add this to `.cursor/mcp.json`:

    ```json
    {
      "mcpServers": {
        "billions-docs": {
          "url": "https://docs.billions.network/mcp"
        }
      }
    }
    ```
  </Tab>
  <Tab title="VS Code">
    Add this to `.vscode/mcp.json`:

    ```json
    {
      "servers": {
        "billions-docs": {
          "type": "http",
          "url": "https://docs.billions.network/mcp"
        }
      }
    }
    ```
  </Tab>
</Tabs>

## Available tools

| Tool | Purpose |
| --- | --- |
| `search_billions` | Search the Billions docs. Returns the matching sections, with titles and links to the pages. |
| `query_docs_filesystem_billions` | Read a full page, or search the docs for an exact keyword, in a read-only copy of the documentation. |
| `submit_feedback` | Report a page that is incorrect, outdated, confusing or incomplete, so the docs team can fix it. |

## When to use it

Use the docs MCP to look up documentation. It reads only the public docs on this site. For help with an integration, contact the [Billions integration team](mailto:support@billions.network).
